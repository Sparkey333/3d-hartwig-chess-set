A. Install on this Mac

  1. 1
    Download the DMG

    Save Neo-Chess-1.1.0-mac.dmg to your Mac Downloads folder (button above). Use the ZIP if the browser blocks disk images.

  2. 2
    Open the DMG

    Double-click the file. If Gatekeeper warns: right-click Neo Chess.app → Open → Open. This local test build is unsigned.

  3. 3
    Drag to Applications

    Drag Neo Chess.app onto the Applications shortcut (or into /Applications). Eject the volume when done.

  4. 4
    Launch

    Open Applications → Neo Chess. Bundled play works offline. Use Setup / Premium for live AI once keys are set.

B. API keys (Premium AI)

  1. 1
    Higgsfield credentials (primary)

    Create KEY_ID:KEY_SECRET for live board skins and replay staging.

    cloud.higgsfield.ai → docs.higgsfield.ai → status.higgsfield.ai →
  2. 2
    OpenAI key (optional fallback)

    Used when Higgsfield is offline or out of credits.

    platform.openai.com/api-keys →
  3. 3
    Put keys in local .env (never commit) HF_CREDENTIALS=KEY_ID:KEY_SECRET OPENAI_API_KEY=sk-... AI_PROXY_PORT=8787

    Then run npm run dev — Vite on :5173, AI proxy on :8787.

  4. 4
    Verify

    Open Premium — status chips should show ready. Generate a theme; it applies live to Play.
