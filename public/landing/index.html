Local Mac setup — clear steps

  1. Rebuild the Mac package on this machine

    From the Neo Chess project root, regenerate DMG/ZIP. Always copies to ~/Downloads and project Downloads/.

    npm install
npm run pack:mac
    • https://vite.dev/ — Vite tooling
  2. Refresh & open the new DMG from ~/Downloads

    After pack (or the buttons above), open the fresh image. First launch: right-click Neo Chess.app → Open.

    open ~/Downloads/Neo-Chess-1.0.0-mac.dmg
# or
npm run open:dmg
  3. Install Neo Chess.app

    Drag Neo Chess.app into Applications (or keep it in Downloads).

  4. Get Higgsfield API credentials (optional Premium AI)

    Live FLUX themes / avatars / replay need server-side credentials. Never use VITE_* — the official SDK blocks browsers.

    • https://cloud.higgsfield.ai — create KEY_ID:KEY_SECRET
    • https://docs.higgsfield.ai — API docs
    • https://github.com/higgsfield-ai/higgsfield-js — JS SDK
    • https://status.higgsfield.ai — status
    export HF_CREDENTIALS="KEY_ID:KEY_SECRET"
npm run dev
  5. Or skip keys — Procedural / Curated skins

    In-app Premium → Board Theme Studio → Procedural or Curated (Hartwig-inspired). Fully offline on this Mac.

  6. Play

    Open the .app, or run the web client. Legacy 3D Hartwig lives at /legacy.

    npm run dev
# → http://localhost:5173
    • https://stockfishchess.org/
    • https://github.com/jhlywa/chess.js
    • https://github.com/Clariity/react-chessboard
